# 模型数据集

## 概述

**模型数据集** 是 Hi168 平台面向 AI 开发与教学的资源管理模块，提供 **AI 模型** 与 **数据集** 两类资源的统一管理能力。用户可以在此创建、上传、检索、发布和共享机器学习模型与训练数据集，并可从 HuggingFace、ModelScope、GitHub 等第三方平台一键导入资源。所有模型与数据集文件均托管在用户的 **存储桶** 中，与平台的存储管理、Notebook 等模块打通，为 AI 实验与项目开发提供基础资源支撑。

> 模型与数据集的文件存放在关联的存储桶内，使用本模块前请先在「存储管理」中创建至少一个存储桶。

---

## 一、进入模块

「模型数据集」默认未固定在桌面，首次使用需先添加：

1. 点击桌面左上角的 **Hi168** 标志，打开应用启动菜单。
2. 在应用列表（可按 **全部 / 基础 / 研发 / 运营 / 教育 / 社区** 分类查看）中找到 **模型数据集**，点击进行安装。
3. 安装后，「模型数据集」图标会出现在桌面，点击即可打开模块。

模块顶部提供 **AI 模型** 与 **数据集** 两个标签页，标签后的数字表示当前资源数量，可随时切换。

---

## 二、AI 模型

### 2.1 功能说明

AI 模型管理用于集中维护个人或组织的模型资源。用户既可以浏览平台内公开的模型，也可以创建、上传自有模型，并按多维度标签进行分类检索。

### 2.2 模型列表与筛选

进入 **AI 模型** 标签页后，左侧为筛选面板，右侧为模型列表。

- **搜索**：在「搜索模型名称」输入框中按名称检索。
- **可见范围**：可在 **我的** 与 **公开** 之间切换。
- **多维标签筛选**：
  - **生成式**：文本生成、文本理解、图像生成、图像理解、音频生成、音频理解、视频生成、视频理解、多模态、代码生成、嵌入/向量化、翻译、摘要/提取、问答、对话、推理/数学、3D 生成、Agent/工具调用。
  - **研究领域**：自然语言处理、计算机视觉、语音与音频、多模态学习、强化学习、推荐系统、图学习、时间序列、生成对抗网络、扩散模型、大语言模型、联邦学习、迁移学习、自监督学习、模型压缩、医学 AI、科学计算、机器人学、自动驾驶、信息检索。
  - **应用领域**：智能客服/对话、内容创作/AIGC、机器翻译、代码开发、数据分析/BI、智能安防、自动驾驶、工业制造、智慧教育、智慧医疗、金融科技、智能运维/AIOps、搜索/推荐、文档处理、游戏/娱乐、农业/环保、法律/合规、人力资源。
  - **框架版本**：PyTorch、TensorFlow、JAX/Flax、PaddlePaddle、MindSpore、ONNX Runtime、Transformers、Diffusers、vLLM、TensorRT-LLM、OpenVINO、llama.cpp、Ollama、MLX、DeepSpeed、Megatron-LM、ColossalAI、Keras、scikit-learn、XGBoost/LightGBM、Sentence Transformers、Detectron2、MMDetection、Ultralytics/YOLO。
- **清空筛选**：点击「全部清空」可重置全部筛选条件。
- **排序**：列表右上角支持「按创建时间」排序。

每个模型卡片展示名称、可见性标签（我的/公开）、创建人以及分类标签。

### 2.3 创建模型

点击右上角 **创建模型**，填写以下信息：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| **模型名称** | 必填 | 用于标识和检索模型，建议使用英文或拼音，最多 20 个字符 |
| **模型描述** | 选填 | 简要说明模型用途、训练数据或适用场景，最多 150 字 |
| **标签分类** | 选填 | 点击「添加标签」，从生成式、研究领域、应用领域、框架版本四类中选择，便于筛选与发现 |
| **可见性** | 必填 | 默认 **私有**（仅自己和组织成员可访问） |
| **模型格式** | 必填 | 可选 SafeTensors、PyTorch (.bin/.pt)、GGUF、GGML、ONNX、TensorFlow SavedModel、TFLite (.tflite)、TensorRT (.engine/.plan)、CoreML (.mlmodel/.mlpackage)、OpenVINO IR (.xml/.bin) |
| **关联存储桶** | 必填 | 选择用于存放模型文件的存储桶，并可在右侧文件列表中查看桶内文件 |

填写完成后点击 **创建模型** 即可。

### 2.4 模型详情与管理

在列表中点击任一模型进入 **模型详情** 页：

- **基本信息**：名称、可见性、描述、分类标签，以及创建人、格式、类型、创建时间、修改时间等元数据；页面底部显示模型 **ID**，可一键复制。
- **顶部操作**：
  - **收起信息**：折叠/展开基本信息区域。
  - **发布为公开**：将私有模型发布为公开，供他人浏览使用。
  - **编辑**：修改模型名称、描述、标签等信息。
  - **删除**：删除该模型。
- **文件标签页**：以文件浏览器形式管理模型文件，支持目录导航、按名称搜索、查看文件大小与最后操作时间，并显示占用空间。点击 **管理文件** 可上传、整理模型文件（文件实际存储在关联的存储桶中）。

## 三、数据集

### 3.1 功能说明

数据集管理用于维护训练、验证与教学所需的数据资源，操作方式与 AI 模型基本一致，支持创建、导入、检索、发布与文件管理。

### 3.2 数据集列表与筛选

切换到 **数据集** 标签页，左侧筛选面板与 AI 模型一致（我的/公开、生成式、研究领域、应用领域等），右侧为数据集列表。每个数据集卡片展示名称、可见性标签、描述摘要、创建人及分类标签，并支持搜索与按创建时间排序。

### 3.3 创建数据集

点击右上角 **创建数据集**，填写以下信息：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| **数据集名称** | 必填 | 用于标识和检索数据集，建议使用英文或拼音，最多 20 个字符 |
| **数据集描述** | 选填 | 说明数据集内容、来源、规模等信息，最多 150 字 |
| **标签分类** | 选填 | 点击「添加标签」从多类标签中选择 |
| **可见性** | 必填 | 默认 **私有**（仅自己和组织成员可访问） |
| **关联存储桶** | 必填 | 选择用于存放数据集文件的存储桶 |

> 与模型不同，数据集无需选择「模型格式」。

### 3.4 数据集详情与管理

数据集详情页与模型详情页布局一致，提供基本信息展示、发布为公开、编辑、删除以及 **文件** 管理等操作，可在关联存储桶中上传与整理数据文件。

## 四、从第三方导入

点击顶部 **从第三方导入**，可从 HuggingFace、ModelScope、GitHub 等平台一键导入模型或数据集。

### 4.1 导入步骤

1. **来源地址**：选择来源平台（**自动识别 / HuggingFace / ModelScope / GitHub / 自定义 URL**），并粘贴资源链接，例如 `https://huggingface.co/meta-llama/Llama-3-8B`。
2. **资源类型**：选择导入为 **AI 模型** 或 **数据集**。
3. **目标名称**：可自定义名称，留空则自动检测。
4. **目标存储桶**：选择用于存放导入文件的存储桶。
5. 点击 **解析 URL** 预览资源信息，确认无误后点击 **开始导入**。

### 4.2 第三方平台账号

导入页面下方的 **第三方平台账号** 区域用于管理访问凭证：

- 以表格形式展示已配置的 **平台、Token、自定义端点、备注** 及操作。
- 点击 **添加账号** 可新增平台凭证；对已有记录可进行 **编辑** 或 **删除**。
- 通过配置 **自定义端点**（如 HuggingFace 镜像地址 `https://hf-mirror.com`）可加速国内访问；对需要鉴权的私有资源，可配置对应的 **Token**。

## 五、最佳实践

1. **先建存储桶**：模型与数据集文件均依赖存储桶，使用前请在「存储管理」中规划好存储桶。
2. **规范命名与描述**：名称建议使用英文或拼音，并完整填写描述与标签，便于团队检索和复用。
3. **善用标签筛选**：上传时按生成式、研究领域、应用领域、框架版本等维度打标签，可显著提升后续查找效率。
4. **合理设置可见性**：默认私有可保护资源安全，确认成熟稳定后再「发布为公开」进行共享。
5. **配置镜像加速导入**：从 HuggingFace 等平台导入时，配置镜像端点与 Token 可提升导入成功率与速度。
