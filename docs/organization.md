# 组织管理

## 概述

Hi168 平台的 **组织管理** 模块为团队协作和企业用户提供核心管理能力。通过组织管理，用户可以创建企业/团队组织或加入已有组织，实现统一的成员管理、余额管理、计费管理和模块配置。组织审核通过后，用户将同时拥有「个人账户」和「企业账户」，可自由切换不同空间进行操作。

---

## 一、组织创建与认证流程

### 1.1 流程说明

组织管理的核心流程如下：

1. **创建或加入组织**：用户选择「创建企业/团队」提交企业信息，或选择「加入企业/团队」申请加入已有组织
2. **管理员审核**：提交后，平台管理员在后台对企业信息进行审核（包括企业名称、统一社会信用代码等）
3. **审核通过**：审核通过后，用户正式拥有组织，获得组织管理权限
4. **邀请成员**：组织拥有者可邀请其他用户加入组织，进行团队协作

### 1.2 创建企业/团队

在桌面中心打开「组织管理」，如果尚未拥有组织，系统会弹出「选择账户」面板，点击「创建企业/团队」按钮，填写以下企业信息提交审核：

| 字段 | 说明 |
| --- | --- |
| **企业名称** | 企业或团队的全称 |
| **统一社会信用代码** | 企业工商注册的唯一识别码 |
| **法定代表人** | 企业法定代表人姓名 |
| **联系电话** | 组织联系电话 |
| **联系邮箱** | 组织联系邮箱 |

### 1.3 加入企业/团队

如果需要加入已有组织，点击「加入企业/团队」按钮，通过组织邀请码或搜索组织名称申请加入。申请提交后，由组织拥有者审批通过即可加入。

### 1.4 管理员审核

提交企业信息后，平台管理员将在后台对信息进行审核，审核内容包括：

- 企业工商信息真实性
- 信用代码有效性
- 企业资质合规性

审核结果会通过平台消息通知用户。审核通过后即可使用组织的全部功能。

## 二、账户切换

### 2.1 功能说明

企业审核通过后，用户将同时拥有**个人账户**和**企业账户**两种身份空间，可以自由切换。

### 2.2 个人账户与企业账户的区别

| 维度 | 个人账户 | 企业账户 |
| --- | --- | --- |
| **余额** | 显示个人余额 | 显示组织余额 |
| **资源** | 个人创建的应用和资源 | 组织下共享的应用和资源 |
| **计费** | 消耗个人余额 | 消耗组织余额 |
| **协作** | 仅个人使用 | 组织成员共享协作 |

### 2.3 切换方式

点击桌面左上角的组织名称或底部的「切换账户」，系统弹出「选择账户」面板，显示：

- **个人账户**：显示用户名和邮箱，标记当前使用状态
- **企业账户**：显示组织名称和用户角色（如拥有者），点击「切换」即可切换到该组织空间

切换后，平台界面中的余额、资源、计费等信息将自动对应当前所选账户空间。

## 三、拥有者与成员可见模块

组织中不同角色看到的功能模块不同：

**拥有者可见模块**：概览、成员、发票管理、余额、计费订阅、拓扑项目、模块、设置

**普通成员可见模块**：概览、成员、拓扑项目

| 功能 | 拥有者 | 普通成员 |
| --- | --- | --- |
| 概览信息 | 余额、成员数、活跃计费、模块配置、最近消费 | 成员数、拓扑项目数、我的角色 |
| 快捷操作 | 邀请成员、余额管理、拓扑项目 | 仅拓扑项目 |
| 成员管理 | 邀请/移除/改角色 | 仅查看列表 |
| 发票/余额/计费/模块/设置 | ✅ 可见可操作 | ❌ 不可见 |

## 四、概览

### 4.1 功能说明

进入组织管理后，默认展示概览页面，显示组织的核心运营数据。

### 4.2 主要信息

| 指标 | 说明 |
| --- | --- |
| **组织可用余额** | 组织当前可用资金余额 |
| **赠送余额** | 平台赠送的免费余额 |
| **成员数** | 当前组织中的成员总数 |
| **活跃计费** | 正在计费中的资源数量 |

### 4.3 模块配置状态

概览页面下方展示组织已开启的功能模块及其状态（如拓扑/云计算、对象存储等）。

---

## 五、成员管理

### 5.1 功能说明

成员管理用于管理组织中的所有成员，组织拥有者可以邀请新成员、设置角色和移除成员。

### 5.2 成员列表

| 字段 | 说明 |
| --- | --- |
| **用户** | 成员用户名和头像 |
| **用户编号** | 成员唯一标识 |
| **角色** | 拥有者 / 普通成员 |
| **加入时间** | 成员加入组织的时间 |
| **操作** | 移除成员（仅针对非拥有者） |

### 5.3 邀请成员

点击「邀请成员」按钮向其他用户发送组织邀请，被邀请用户接受后将以普通成员身份加入组织。

### 5.4 角色说明

| 角色 | 权限 |
| --- | --- |
| **拥有者** | 最高权限，可管理所有设置、成员、余额分配 |
| **普通成员** | 可使用组织分配的资源，无管理权限 |

---

## 六、余额管理

### 6.1 功能说明

余额管理用于管理组织的资金，支持充值、为成员分配余额和查看消费明细。

### 6.2 余额概览

| 指标 | 说明 |
| --- | --- |
| **可用余额** | 当前可使用的余额 |
| **赠送余额** | 平台赠送的余额 |
| **冻结金额** | 因未完成交易被冻结的金额 |
| **累计充值** | 历史充值总额 |
| **累计消费** | 历史消费总额 |

### 6.3 成员余额分配

组织拥有者可将组织余额分配给成员使用：

| 操作 | 说明 |
| --- | --- |
| **分配** | 为成员分配指定金额的余额 |
| **回收** | 回收成员未使用的余额 |
| **预算** | 设置成员使用预算上限 |

### 6.4 消费流水

记录组织所有消费明细，包含时间、类型、金额和详细说明（如应用部署按时扣费信息），支持分页查看。

---

## 七、计费订阅

### 7.1 功能说明

计费订阅页面展示组织中所有资源的计费情况。

### 7.2 计费状态

| 状态 | 说明 |
| --- | --- |
| **活跃** | 资源正在运行并持续计费 |
| **已暂停** | 资源暂停运行，暂停计费 |
| **已停止** | 资源已停止，不再计费 |

### 7.3 计费列表字段

| 字段 | 说明 |
| --- | --- |
| **资源** | 资源名称和类型（应用部署/拓扑设备等） |
| **创建者** | 创建该资源的成员 |
| **计费模式** | 计费方式（如按小时） |
| **单价×数量** | 资源单价及使用数量 |
| **累计消费** | 该资源累计消费金额 |
| **下次扣费** | 下一次自动扣费时间 |

支持按状态和资源类型筛选。

---

## 八、发票管理

### 8.1 功能说明

发票管理用于维护组织的发票抬头信息和查看开票记录。

### 8.2 发票抬头

管理组织的发票抬头信息，点击「新建抬头」添加：

- 名称（公司名称）
- 税号（纳税人识别号）
- 开户行

### 8.3 开票记录

切换到「开票记录」标签页查看历史开票信息。

---

## 九、拓扑项目

### 9.1 功能说明

展示组织下的共享拓扑项目列表，方便团队协作网络仿真实验。

### 9.2 项目信息

| 字段 | 说明 |
| --- | --- |
| **项目名** | 拓扑项目名称 |
| **创建者** | 项目创建者 |
| **设备数** | 项目中的网络设备数量 |
| **状态** | 项目状态（draft/running等） |
| **更新时间** | 最后更新时间 |

## 十、模块配置

### 10.1 功能说明

模块配置用于管理组织可使用的功能模块，拥有者可根据需要开启或关闭。

### 10.2 可配置模块

| 模块 | 标识 | 说明 |
| --- | --- | --- |
| 拓扑/云计算 | topo | 网络拓扑和云计算资源 |
| 对象存储 | s3 | 文件存储与共享服务 |
| 教育 | edu | 课程、班级等教育功能 |
| AI/LLM | ai | AI 大语言模型功能 |
| 社区 | community | 社区交流 |
| 即时通讯 | chat | 组织内即时通讯 |
| 科研 | research | 科研相关功能 |

每个模块通过开关按钮控制启用/禁用状态。

---

## 十一、设置

### 11.1 基本信息

编辑组织基础资料：

| 字段 | 说明 |
| --- | --- |
| **组织名称** | 组织全称 |
| **组织简称** | 用于界面显示的简短名称 |
| **描述** | 组织简要描述 |
| **网站** | 组织官方网站 |
| **联系人** | 联系人姓名 |
| **电话** | 联系电话 |
| **邮箱** | 联系邮箱 |

修改后点击「保存设置」保存。

### 11.2 企业认证

企业认证提供三级认证体系：

| 等级 | 方式 | 说明 |
| --- | --- | --- |
| Level 1 | 工商核验 | 自动秒级验证，通过工商信息核实企业身份 |
| Level 2 | 对公打款 | 银行流水验证，通过对公账户验证 |
| Level 3 | 授权函认证 | 最高等级，提交授权函完成认证 |

完成全部认证后，组织将获得「完全认证」标识。

### 11.3 危险操作

设置页面底部包含「解散组织」功能。解散后所有数据永久删除，操作不可逆。
