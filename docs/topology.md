# 拓扑管理

## 概述

Hi168 平台的 **拓扑管理** 模块提供可视化的网络与基础设施拓扑编排能力。用户可通过桌面端图形化界面设计、构建和管理复杂的网络拓扑结构，直观地编排交换机、路由器、防火墙、服务器、PC 终端等各类网络设备及其互联关系，广泛应用于网络工程教学、实验环境搭建和架构设计等场景。

---

## 一、功能说明

拓扑管理采用所见即所得的可视化编辑模式，将抽象的网络架构转化为直观的图形表示，降低拓扑设计的复杂度。

### 1.1 核心特性

| 特性 | 说明 |
| --- | --- |
| **可视化画布** | 提供可缩放的画布，支持拖拽式拓扑设计 |
| **丰富设备库** | 内置交换机、路由器、防火墙、服务器、PC 终端等多厂商多型号的网络设备 |
| **连线与互联** | 通过连线工具定义设备之间的网络连接关系 |
| **缩放与导航** | 支持放大、缩小、重置缩放、自适应画布等视图操作 |
| **文件管理** | 支持拓扑文件的新建、上传、搜索、分类和公开/私有管理 |
| **团队协作** | 支持按团队管理拓扑文件，便于教学和团队协作 |
| **设备模板** | 支持设备模板的创建、导入、导出和管理 |
| **实时部署** | 编排完成后可一键启动拓扑中的所有节点 |

---

## 二、界面布局

拓扑管理模块包含两个主要视图：**拓扑文件列表**和**拓扑编辑器**。

### 2.1 拓扑文件列表

进入拓扑管理后，默认显示拓扑文件列表页面。

**左侧导航栏：**

| 区域 | 说明 |
| --- | --- |
| **我的文件** | 浏览个人创建的拓扑文件 |
| **最近使用** | 快速访问最近编辑过的拓扑 |
| **团队** | 按团队分组管理拓扑，支持创建新团队 |
| **分类** | 按用途分类浏览：通用、IT、商务、工程、教育科学 |
| **管理** | 进入我的模板管理页面 |

**顶部操作区：**

| 功能 | 说明 |
| --- | --- |
| **文件筛选** | 切换查看「全部文件」「我的」「公开」三种范围 |
| **搜索** | 按拓扑名称关键字搜索 |
| **新建** | 创建一个新的拓扑文件 |
| **打开文件夹** | 从本地打开拓扑文件 |
| **上传** | 上传本地拓扑文件（.topo 格式） |

**文件列表字段：**

| 列名 | 说明 |
| --- | --- |
| **拓扑名称** | 拓扑文件名称，点击可进入编辑器 |
| **类型** | 文件类型（拓扑文件） |
| **创建者** | 拓扑文件的创建用户 |
| **归属** | 归属为个人或团队 |
| **发布日期** | 创建或最后修改日期 |
| **状态** | 公开状态（未公开 / 已公开），支持筛选 |
| **操作** | 打开文件所在目录等操作 |

所有列支持排序（点击列头切换升序/降序）。

### 2.2 拓扑编辑器

点击拓扑文件名称进入拓扑编辑器，界面分为以下区域：

#### 2.2.1 顶部工具栏

**面包屑导航**：显示当前路径（拓扑管理 > 拓扑文件名），点击「拓扑管理」可返回列表。

**操作工具：**

| 工具 | 说明 |
| --- | --- |
| **启动（▶）** | 启动当前拓扑中的所有设备节点 |
| **停止（■）** | 停止当前拓扑中所有运行中的节点 |
| **文本标注（T）** | 在画布上添加文本标注 |
| **矩形** | 绘制矩形区域，用于标注逻辑分组 |
| **网格模式** | 切换网格辅助线显示 |
| **图片** | 在画布中插入图片 |

**右侧工具：**

| 工具 | 说明 |
| --- | --- |
| **团队协作** | 管理拓扑的团队共享设置 |
| **快照** | 保存/恢复拓扑快照 |
| **设置** | 配置拓扑的全局参数 |

#### 2.2.2 设备面板（左侧）

左侧为可折叠的设备面板，提供可拖拽的网络设备组件：

| 设备分类 | 说明 |
| --- | --- |
| **交换机** | 二层交换设备（华为 CE12800/CE6800、H3C S10500V/S9850、Cisco Nexus、Arista vEOS、Juniper vQFX 等） |
| **路由器** | 三层路由设备（华为 AR/NE 系列、Cisco vIOS、Juniper vSRX 等） |
| **防火墙** | 安全设备（华为 USG、FortiGate、Palo Alto、pfSense 等） |
| **连线** | 定义设备之间的网络连接 |
| **服务器** | 物理/虚拟服务器节点（Linux、Windows Server、Zabbix 等） |
| **PC 终端** | 终端设备（Desktop PC、Laptop 等） |
| **其他设备** | 无线 AP、云设备、负载均衡器等其他设备类型 |

设备面板顶部提供搜索框，可按设备名称快速筛选。

#### 2.2.3 拓扑画布

中央区域为拓扑画布，用户在此进行拓扑的可视化编排：

- **拖放设备**：从左侧设备面板拖拽设备到画布中放置。
- **连接设备**：使用连线工具在两个设备之间建立网络连接。
- **移动与排列**：拖动已放置的设备调整位置，优化拓扑布局。
- **属性编辑**：双击设备可编辑其属性参数。

#### 2.2.4 浮动工具栏

画布上方显示浮动工具栏（可拖拽移动），提供视图控制：

| 工具 | 说明 |
| --- | --- |
| **放大** | 放大画布显示比例 |
| **缩小** | 缩小画布显示比例 |
| **重置缩放** | 恢复到默认缩放比例 |
| **自适应画布** | 自动调整缩放使所有设备完整显示在视口中 |

## 三、拓扑文件管理

### 3.1 创建拓扑

1. 在拓扑文件列表页，点击顶部「新建」按钮。
2. 输入拓扑名称，系统会自动创建并进入编辑器。

### 3.2 上传拓扑

1. 点击「上传」按钮（↑ 图标）。
2. 选择本地的 `.topo` 格式拓扑文件。
3. 上传完成后，文件出现在列表中。

### 3.3 搜索与筛选

- 使用搜索框按名称搜索拓扑文件。
- 通过「全部文件」「我的」「公开」切换查看范围。
- 点击「状态」列的筛选图标，按公开状态过滤。
- 点击列头进行排序。

### 3.4 分类管理

左侧「分类」支持按场景筛选拓扑：

| 分类 | 适用场景 |
| --- | --- |
| **通用** | 通用网络拓扑 |
| **IT** | IT 基础设施相关拓扑 |
| **商务** | 企业办公网络拓扑 |
| **工程** | 工程项目相关拓扑 |
| **教育科学** | 教学实验拓扑 |

### 3.5 团队管理

- 点击「团队」区域的 `+` 按钮创建新团队。
- 团队成员可共享和协作编辑拓扑文件。
- 拓扑文件的「归属」字段标识其属于个人或团队。

## 四、拓扑编排操作

### 4.1 添加设备

1. 在编辑器左侧设备面板中选择设备分类（交换机、路由器等）。
2. 在设备列表中找到目标设备型号（可通过搜索框筛选）。
3. 将设备拖拽到画布中放置。

### 4.2 建立连接

1. 在设备面板中选择「连线」工具。
2. 在画布中从一个设备拖动到另一个设备，建立网络连接。
3. 连线会自动显示在两个设备之间。

### 4.3 部署与运行

1. 拓扑编排完成后，点击顶部工具栏的「启动（▶）」按钮。
2. 系统按照拓扑定义自动创建和配置所有节点。
3. 节点启动后，用户可点击节点进入其控制台操作界面。
4. 需要停止时，点击「停止（■）」按钮关闭所有节点。

### 4.4 画布操作

- **缩放**：使用浮动工具栏的放大/缩小按钮，或鼠标滚轮缩放。
- **自适应**：点击「自适应画布」使所有设备完整显示。
- **折叠面板**：点击面板边缘的折叠按钮隐藏设备面板，获得更大画布空间。
- **全屏**：点击标题栏的全屏图标进入全屏编辑模式。

## 五、我的模板

在左侧导航的「管理 > 我的模板」中管理个人设备模板：

| 功能 | 说明 |
| --- | --- |
| **创建模板** | 新建一个自定义设备模板 |
| **导入模板** | 从文件导入设备模板 |
| **导出** | 将模板导出为文件 |
| **编辑** | 修改模板参数 |
| **删除** | 删除模板 |
| **启动测试** | 启动模板进行测试验证 |

我的模板字段：模板名称、类型、CPU、内存、磁盘、网口、控制台。

## 六、典型使用场景

### 6.1 网络工程教学

- 教师设计网络拓扑实验，学生通过可视化界面理解网络架构。
- 搭建包含路由器、交换机、防火墙的企业级网络实验环境。
- 实践 VLAN 划分、路由协议配置、ACL 策略设置等网络实验。
- 利用团队功能，教师为班级创建团队，统一下发实验拓扑。

### 6.2 系统架构设计

- 构建微服务架构的拓扑示意图，规划服务间的网络通信。
- 设计高可用集群的部署拓扑，验证故障转移策略。

### 6.3 网络安全实验

- 搭建包含攻防环境的网络拓扑，开展渗透测试实训。
- 配置防火墙规则，实践网络安全策略的部署与验证。

### 6.4 多厂商设备实训

- 支持华为、H3C、Cisco、Juniper、Arista、Fortinet 等主流厂商设备模拟。
- 在同一拓扑中混合使用不同厂商设备，模拟真实多厂商网络环境。

## 七、最佳实践

1. **先规划后编排**：在开始拖拽之前，先明确拓扑的整体架构和网络分段策略。
2. **合理使用分类**：创建拓扑时选择合适的分类，方便后续管理和查找。
3. **规范命名**：为拓扑文件和节点设置有意义的名称，方便在复杂拓扑中快速识别。
4. **善用搜索**：设备面板和文件列表均支持搜索，在设备众多时利用搜索快速定位。
5. **团队协作**：教学或团队项目中使用团队功能统一管理拓扑文件。
6. **模板复用**：将常用设备配置保存为模板，便于在多个拓扑中快速复用。
